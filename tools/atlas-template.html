01 · Принципы

Четыре идеи, на которых всё держится

01

Палаццо — это интерфейс

Навигация повторяет реальное здание: план двух этажей, залы 1–16 в порядке обхода и виртуальный зал 17. Пользователь всегда видит, где он находится.

02

Два голоса — два цвета

Синий — Артур Джафа, оранжевый — Ричард Принс. Цвета кодируют автора везде: точки на плане, подписи карточек, логотип.

03

Искусство впереди интерфейса

Нейтральные поверхности и крупные фото. Обложки работ без фото — абстракции в духе работы, а не чужие кадры.

04

Доступно для всех

Контраст текста по WCAG AA во всех скинах, кнопки не меньше 38 px, тема следует настройке устройства, отдельный скин высокого контраста.

02 · Скины

Пять скинов на одних токенах

Скин меняет только значения CSS-переменных — разметка и компоненты одни и те же. Выбор — кнопка ◐ в шапке сайта; по умолчанию сайт берёт светлую или тёмную тему из системы. Для показа заказчику любой скин открывается ссылкой вида index.html?skin=laguna.

03 · Токены

Цветовые токены

Значения считаны из index.html при сборке атласа. Колонка «контраст» — соотношение цвета текста с фоном, на котором он используется (норма AA: 4.5 для текста, 3 для крупного).
